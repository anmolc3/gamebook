# 🌈 The Five Theme Families (Marvie Adaptation)

The application features 5 hand-crafted theme families. Each theme features meticulously designed **Light** and **Dark** variants that preserve game readability while projecting a distinct brand identity. The lead theme is **Marvie Slate / Mint**, adapting the core visual identity of `download_marvie-ios-ui-kit-for-sketch.sketch`.

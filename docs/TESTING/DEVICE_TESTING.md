# 📱 Device Compatibility Testing Matrix

## Device Profiles
1. **Small Screen Android**: 320x568 / 360x640 (Check padding reduction and zero horizontal clipping).
2. **Standard Android**: 390x844 / 412x915 (Standard baseline).
3. **Phablet / Tablet**: 600x1024+ (Validate max-width constraints on card containers).
4. **Notch & Dynamic Island**: Verify safe-area inset top and bottom behaviors.

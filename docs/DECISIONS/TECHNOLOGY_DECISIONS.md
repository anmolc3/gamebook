# ⚙️ Technology Decision Records (TDR)

## TDR-001: Selection of React Native + Expo
- **Reason**: Delivers native 60 FPS mobile performance across Android devices with streamlined TypeScript support and rapid over-the-air testing.

## TDR-002: Selection of Node.js + Express + Socket.IO
- **Reason**: Unified TypeScript runtime between client and server, mature bi-directional event gateways, massive ecosystem, and minimal operational overhead for free-first deployments.

## TDR-003: Selection of PostgreSQL + Prisma ORM
- **Reason**: ACID compliance for transactional game statistics, powerful relational indexes for social graphs, and type-safe query generation via Prisma.
